Library Management System 📚

A simple Library Management System built using Python that allows users to display available books, borrow books, and save book records to a text file.

Features
Display available books
Borrow books
Check book availability
Save books to a text file
Simple menu-driven interface
Technologies Used
Python
Lists and Tuples
Functions
Loops and Conditional Statements
File Handling
How to Run
Install Python on your computer.
Download or clone this repository.
Open the project folder in your terminal.
Run the following command:
bash
python library.py

Menu Options
Display Books
Borrow Book
Save File
Exit
File Handling

The program saves available books in a file named books.txt.

Project Objective

This project helps beginners learn Python programming concepts such as lists, tuples, functions, loops, conditional statements, and file handling.
